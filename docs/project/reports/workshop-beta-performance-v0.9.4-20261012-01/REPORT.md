# Public Beta v0.9.4 性能优化候选

本次以 v0.9.3 发布目录的实际构建源码和 ZIP 为基线，在此独立目录交付 v0.9.4。正式安装未替换，Steam Workshop 未上传，真人复测仍为 PENDING。玩法合同、90 模型、数值和存档格式保持 V1.3。

## 使用

- `FSN-RinArcher-Public-Beta-v0.9.4.zip`：最终 27 文件发布包，不含 QA 操作器、游戏本体或两个依赖。
- `启动-Public-Beta-v0.9.4.cmd`：本机独立试玩入口，使用独立 Profile 和本机已安装的游戏资源、两个依赖；不是供其他电脑直接使用的分发包。
- `INSTALL.md`：依赖、支持版本、安装及真人复测要点。
- `build/source/`：本候选源码；`source-changes.diff` / `source-changes.json` 对照 v0.9.3。

## 已完成的优化

1. 卡牌外观与排版缓存：第三方备用手牌控件每约 0.1 秒触发原生卡牌刷新，原先每次又重设整套外观、字号和布局。现在只在卡牌、语言、稀有度或实际文本/几何变化时重复这些工作；原生动态费用和可用状态仍照常更新。
2. 双血条、费用与角色标签按状态变化更新；角色节点引用与静态翻译缓存；隐藏调试面板不再构造正文，不可见的选人/篝火视觉不再持续请求重绘。双血条仍每帧检查父容器造成的几何变化，避免缩放时错位。
3. 诊断日志改为有界队列、后台批量落盘和约 2 MiB 轮转，文件被占用或无权限不会打断战斗。默认关闭高频控制台输出与无限累积的内存遥测；真实存档写入和校验不经过日志队列。
4. 删除游戏安装目录内的启动探针写入；不兼容游戏构建在菜单显示原因，阻止该角色选择、开局和继续；现存存档不被该拦截逻辑改写。
5. 卡牌正文最小字号从 11 提高到 14，增加正文区域，精简英文强化投影措辞；修正 Workshop 独立行动说明，并补充实际双手牌战斗截图。

## 性能证据

图形模式、1920×1080、同一本轮自然生成的首战存档 `MA1JRJUUZ9`，各采样约 10 秒。两次均启用相同计时探针与 UI 测试操作器，未编辑种子、牌组或生命。原始采样 JSON 的通用说明仍写着 seeds differ；本次实际同存档来源另见 `PERFORMANCE_PROVENANCE.json` 和双方截图。

| 指标 | v0.9.3 | v0.9.4 |
|---|---:|---:|
| 卡牌外观刷新，平均毫秒/次 | 2.084 | 0.016 |
| 双血条刷新，平均毫秒/次 | 0.144 | 0.010 |
| 角色视觉 Tick，平均毫秒/次 | 0.044 | 0.002 |
| 费用监听，平均毫秒/次 | 0.0055 | 0.0018 |
| 主循环帧间隔平均值，毫秒 | 17.95 | 17.01 |
| 主循环帧间隔 P95，毫秒 | 40.24 | 32.92 |
| 主循环帧间隔 P99，毫秒 | 60.57 | 45.37 |
| 全进程托管分配量，约 10 秒 | 424.4 MB | 402.3 MB |

卡牌外观热点耗时降低约 99.2%，但不能解释为整款游戏快了 99%。本次单样本 P95 改善约 18%，没有统计显著性结论；这不是 GPU 呈现帧率测量。HUD Update 单样本耗时反而升高，完整结果保留在 `PERFORMANCE_COMPARISON.json`，没有只挑有利项。游戏和测试器仍有其他分配和卡顿来源，长战斗、复杂特效、多 MOD 组合及真人体验未获得性能保证。
