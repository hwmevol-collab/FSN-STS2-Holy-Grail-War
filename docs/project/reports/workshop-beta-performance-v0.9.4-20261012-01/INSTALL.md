# v0.9.4 安装与复测

测试基线：游戏 v0.107.1 / commit 59260271；BaseLib 3.4.7；RitsuLib 0.6.6 的 0.107.1 API 分支。当前并非“此版本及以上均兼容”。不同构建会显示版本提示，等待适配后再开凛 / Archer 的 Run。

手动安装：先备份现有 MOD 与存档，将 ZIP 中 mods/RinArcherCore 整个文件夹放入游戏 mods 目录。只启用一个 RinArcherCore 版本，并启用两个依赖。正式 Steam 安装未由本次任务自动修改。

本机试玩：双击本目录的“启动-Public-Beta-v0.9.4.cmd”，使用独立安装及新 Profile，不覆盖正式游戏存档。测试操作器不会放入试玩目录或 ZIP。

玩法和存档格式仍为 V1.3；本次工程 Continue 检查使用测试生成的存档副本。更早玩法版本不自动迁移。

建议先观察：战斗静止时是否仍周期卡顿、连续出牌与切换是否顺畅、费用/双血条是否即时更新、英文长卡说明能否阅读。真人手感、联机、实体手柄和长期平衡仍待确认。

诊断日志现异步写入，单文件约 2 MiB 后轮转，保留一份上一段；高负载时可丢弃旧诊断行，突然退出可能丢失最后一小段。真实存档不使用此队列，校验仍严格。需要详细调试时，可仅为单次启动设置 FSN_VERBOSE_LOGS=1。
