# Recovery and continuation / 恢复与接续

1. Clone this public repository, or extract the private final archive into a chosen empty recovery directory. Restore all archive payloads and hardlink maps as described by ARCHIVE_INDEX.md; do not overwrite an existing game or profile.
2. Use src/ and loader/ for the final branch. docs/project/CURRENT_STATE.md and earlier milestones are historical snapshots; root CURRENT_STATE.md is the final status. C# is copied unchanged from visual-loader-fix-01; inherited Directory.Build.targets' nine Matrix JSON resources are now explicitly embedded from src/Compatibility.
3. Install .NET SDK 9. Obtain the exact reviewed Windows game builds (verified-games.json); supply separate directories for 0.107.1 and 0.111.0. Obtain BaseLib 3.4.7 and full RitsuLib 0.6.7 compat/shared libraries. These are not included in Git.
4. Run tools/Build.ps1 with explicit paths. Loader references the older reviewed game API; GAME_0107 is selected through RitsuLibReferenceTarget. Content assembly names, model IDs, save keys, gameplay and strict identity guards stay unchanged. A rebuilt content DLL gets a new SHA; never reuse a manifest with stale payload hashes.
5. For a C# continuation, obtain the final release's existing shared MOD resources and pass its ZIP to tools/Package.ps1; the two new content DLLs and Loader are inserted and the manifest regenerated. Godot scripts/scenes are under godot/; binary asset requirements are listed in ASSET_REQUIREMENTS.json. The complete source art/video library is private backup material, not a repository dependency.
6. history/ contains 13 major source snapshots plus the separate legacy Saber MOD. Releases group the final Windows beta, early milestone test packages, and superseded compatibility candidates. Android-related historical candidates retain their known-fault notices; they are not supported Android builds.
7. Future debugging can install the saved sts2-modding Skill without the original workspace. Its references contain reusable API/lifecycle/ownership lessons, tested identities and the final visual/path fixes. Project evidence is under docs/project/reports/ and the full private archive; private chats and credentials are not public.

No complete natural Run, all-vanilla coverage, network/controller acceptance or Android acceptance is added by closeout. Rights/copyright requests: use the original Workshop comments/discussions linked in README. Repository visibility does not grant a new code or asset license.
